### 六、计算题答案（第11章）

1. **EV = 50% × 800 = 400万元**
2. **SV = EV - PV = 400 - 500 = -100万元**（进度落后）  
   **SPI = EV / PV = 400 / 500 = 0.8**（进度效率80%）
3. **CV = EV - AC = 400 - 450 = -50万元**（成本超支）  
   **CPI = EV / AC = 400 / 450 = 0.889**（成本效率88.9%）
4. **进度落后，成本超支**
5. **ETC = (BAC - EV) / CPI = (800 - 400) / 0.889 = 450万元**  
   **EAC = AC + ETC = 450 + 450 = 900万元**
6. **VAC = BAC - EAC = 800 - 900 = -100万元**（预计超支100万）
7. **TCPI = (BAC - EV) / (BAC - AC) = (800 - 400) / (800 - 450) = 400 / 350 = 1.14**
