# 第17章 项目干系人管理 知识点总结

> 学习日期：2026-04-22
> 页码范围：第518-534页

---

## 一、概念与重要性

**干系人**：能够影响项目或受项目影响的人员、团体或组织。

**核心目标**：提高项目成功概率，尽早识别干系人并引导其参与。干系人满意度应作为项目目标加以识别和管理。

**关键点**：
- 尽早开始（项目章程批准后即可开展）
- 持续沟通，理解需求和期望
- 识别干系人活动需**迭代开展**（项目阶段变化、新干系人出现时）

### 干系人管理的重要性
- 每个项目都有干系人，有些对项目有重大影响
- 项目经理和团队管理干系人的能力决定项目成败
- 有效引导干系人参与的关键：重视所有干系人、保持持续沟通

### 新实践和发展趋势
- 识别所有干系人，而非限定范围
- 确保所有团队成员都涉及引导干系人参与
- 定期审查干系人群体
- 应用"共创"概念，视为合作伙伴
- 关注干系人有效参与程度的正面与负面价值

---

## 二、四大管理过程（必背）

| 过程 | 主要作用 |
|------|---------|
| **识别干系人** | 建立对每个干系人的适度关注 |
| **规划干系人参与** | 制定有效互动的可行计划 |
| **管理干系人参与** | 提高支持度，降低抵制程度 |
| **监督干系人参与** | 维持或提升参与效率和效果 |

---

## 三、识别干系人

### 输入
- 立项管理文件
- 项目章程
- 项目管理计划：沟通管理计划、干系人参与计划
- 项目文件：需求文件、问题日志、变更日志
- 协议
- 事业环境因素
- 组织过程资产

### 工具与技术
- **专家判断**
- **数据收集**：问卷调查、头脑风暴/头脑写作
- **数据分析**：干系人分析（核心）
- **数据表现**：干系人映射分析和表现

### 干系人分析（重要）
干系人分析会产生干系人清单和相关信息：组织内岗位、项目角色、利害关系、期望、态度、对项目信息的兴趣

**干系人的利害关系组合**：
- **兴趣**：个人或群体受决策或成果的影响
- **权利**：合法权利（法律框架规定）或道德权利（历史遗迹/环境保护）
- **所有权**：对资产或财产的法定所有权
- **知识**：专业知识有助于达成目标或了解权力结构
- **贡献**：提供资金、资源、人力资源，或宣传项目目标

### 干系人分类模型（重要）
1. **权力利益方格/权力影响方格/作用影响方格**：基于权力、利益、影响能力分类
2. **干系人立方体**：上述方格的三维改良形式
3. **凸显模型**：权力+紧迫性+合法性（可用邻近性取代合法性）
4. **影响方向**：向上（高级管理层）、向下（团队专家）、向外（外部群体）、横向（同级人员）
5. **优先级排序**：对干系人进行优先级排序

### 输出
1. **干系人登记册**（主要输出）：
   - 身份信息：姓名、职位、地点、联系方式、角色
   - 评估信息：主要需求、期望、影响潜力、最能影响的项目生命周期阶段
   - 干系人分类：内部/外部、上下级/外围/横向等

2. 变更请求
3. 项目管理计划更新：需求管理计划、沟通管理计划、风险管理计划、干系人参与计划
4. 项目文件更新：假设日志、问题日志、风险登记册

## 四、规划干系人参与

### 触发更新的情况
- 项目新阶段开始
- 组织结构或行业内部发生变化
- 新干系人出现或现有干系人不再是成员
- 干系人对项目成功的重要性发生变化
- 其他项目过程输出导致需要重新审查

### 输入
- 项目章程
- 项目管理计划：资源管理计划、沟通管理计划、风险管理计划
- 项目文件：假设日志、风险登记册、干系人登记册、项目进度计划、问题日志、变更日志
- 协议
- 事业环境因素
- 组织过程资产

### 工具与技术
- 专家判断
- **数据收集**：标杆对照
- **数据分析**：假设条件和制约因素分析、根本原因分析
- **决策**：优先级排序或分级
- **数据表现**：
  - 思维导图（可视化整理）
  - **干系人参与度评估矩阵**（核心工具）⭐

### 干系人参与度评估矩阵（⭐重要）

| 参与水平 | 说明 |
|---------|------|
| 不了解型 | 不知道项目及其潜在影响 |
| 抵制型 | 知道但反对变更，不支持项目工作或成果 |
| 中立型 | 了解，既不支持也不反对 |
| 支持型 | 了解并支持项目工作及其成果 |
| **领导型** | 了解且积极参与以确保项目成功 |

> **C = 当前参与水平（Current），D = 期望参与水平（Desired）**
> 弥合当前与期望参与水平的差距是监督干系人参与的核心工作

### 输出
- **干系人参与计划**：项目管理计划的组成部分，制定有效参与和执行决策的策略和行动

## 五、管理干系人参与

### 核心活动
1. 在适当项目阶段引导干系人参与，获取、确认或维持承诺
2. 通过谈判和沟通管理干系人期望
3. 处理干系人管理有关的任何风险或潜在关注点
4. 澄清和解决已识别的问题

### 输入
- 项目管理计划：沟通管理计划、风险管理计划、干系人参与计划、变更管理计划
- 项目文件：问题日志、干系人登记册、变更日志、经验教训登记册
- 事业环境因素
- 组织过程资产

### 工具与技术
- 专家判断
- **沟通技能**：反馈机制（正式/非正式对话、问题识别、进展报告、调查）
- **人际关系与团队技能**：
  - 冲突管理
  - 文化意识
  - 谈判
  - 观察和交谈
  - 政策意识
- 基本规则
- 会议

### 输出
1. 变更请求
2. 项目管理计划更新：沟通管理计划、干系人参与计划
3. 项目文件更新：变更日志、问题日志、经验教训登记册、干系人登记册

---

## 六、监督干系人参与

### 输入
- 项目管理计划：资源管理计划、沟通管理计划、干系人参与计划
- 项目文件：风险登记册、干系人登记册、问题日志、项目沟通记录、经验教训登记册
- 工作绩效数据
- 事业环境因素
- 组织过程资产

### 工具与技术
- **数据分析**：备选方案分析、根本原因分析、干系人分析
- **决策**：多标准决策分析、投票
- **数据表现**：干系人参与度评估矩阵（核心，跟踪参与水平变化）⭐
- **沟通技能**：反馈、演示
- **人际关系与团队技能**：
  - 积极倾听
  - 文化意识
  - 领导力
  - 人际交往
  - 政策意识
- 会议

### 输出
1. **工作绩效信息**：干系人当前支持水平与期望水平的比较结果
2. 变更请求
3. 项目管理计划更新：资源管理计划、沟通管理计划、干系人参与计划
4. 项目文件更新：问题日志、经验教训登记册、风险登记册、干系人登记册

---

## 七、敏捷与适应方法

- 频繁变化的项目更需要干系人有效互动和参与
- 适应型团队直接与干系人互动，而非通过层层管理级别
- 客户、用户和开发人员在动态共创过程中交换信息
- 整个项目期间保持与干系人群体的互动
- 敏捷型方法提倡高度透明：邀请所有干系人参与项目会议和审查

---

## 八、裁剪考虑因素

裁剪项目干系人管理过程时应考虑：
- **干系人多样性**：现有干系人数量、文化多样性情况
- **干系人关系的复杂性**：关系网络复杂度
- **沟通技术**：可用沟通技术及支持机制

## 九、练习题答案

### 选择题
1. **D**（变更请求不属于识别干系人的输入）
2. **C**（风险登记册不是识别干系人的依据）
3. **A**（监督干系人参与的作用是维持或提升参与活动的效率和效果）

### 判断题
1. **✗**（干系人管理过程包括4个，不是3个）
2. **✓**（干系人包括项目团队成员）
3. **✗**（识别干系人应定期开展，不是一次）

### 问答题
1. **识别干系人的时间点**：
   - 项目进入不同生命周期阶段
   - 当前干系人不再与项目工作有关，或出现新干系人
   - 组织内或更大领域发生重大变化

2. **监督干系人参与的输出**：
   - 工作绩效信息
   - 变更请求
   - 项目管理计划更新
   - 项目文件更新
