## 15.1 管理基础

### 15.1.1 项目风险概述

**核心定义：**
- 项目风险 = 不确定的事件或条件，一旦发生对项目目标产生正面或负面影响
- 风险既包括威胁（Threat），也包括机会（Opportunity）
- 已知风险 → 可识别、分析、规划应对方案
- 未知风险 → 无法管理，但可采取一般应急措施

**两个层面：**
1. 单个风险：影响特定项目目标
2. 整体项目风险：由单个风险+其他不确定性来源联合导致

### 15.1.2 风险属性

| 属性 | 说明 |
|------|------|
| **随机性** | 风险发生及其后果具有偶然性，遵循统计规律 |
| **相对性** | 风险相对主体而言，同一风险对不同主体影响不同 |
| **可变性** | 性质可变、后果可变、出现新风险（辩证转化） |

**风险态度（按图15-1）：**
- 风险规避者：投入越大，要求成功概率越高
- 风险中性 / 风险偏好者：可接受较低成功概率

### 15.1.3 风险分类

**按后果：**
| 类型 | 特点 |
|------|------|
| 纯粹风险 | 只能造成损失，无获利可能（零和以下） |
| 投机风险 | 可能获利+可能损失（第三者可获利） |

**按来源：**
- 自然风险 vs 人为风险（行为/经济/技术/政策/组织）

**按可预测性：**
| 类型 | 例子 |
|------|------|
| 已知风险 | 目标不明确、过分乐观进度计划、变更、材料价格波动 |
| 可预测风险 | 业主不能及时审批、分包商延迟、设备故障 |
| 不可预测风险 | 地震、百年不遇暴雨、通胀、政策变化 |

### 15.1.4 风险成本

```
风险成本 = 有形成本 + 无形成本 + 预防控制成本
```

**有形成本：** 直接损失（财产损毁、人员伤亡）+ 间接损失（停工、灭火扑救）
**无形成本：** 减少机会、阻碍生产率提高、资源分配不当
**风险成本负担：** 个体负担 + 社会负担

### 15.1.5 管理新实践

| 新实践 | 说明 |
|--------|------|
| 非事件类风险 | 变异性风险（蒙特卡洛分析）+ 模糊性风险（专家意见/增量开发） |
| 项目韧性 | 为突发性风险预留应急预算和时间，授权项目团队 |
| 整合式风险管理 | 项目/项目集/项目组合/组织各层面风险管理一致性 |

## 15.3 规划风险管理

**作用：** 定义如何实施项目风险管理活动

### 输入
- 项目章程
- 项目管理计划（各子计划、成本管理计划、进度管理计划）
- 项目文件（干系人登记册、经验教训登记册）
- 事业环境因素
- 组织过程资产

### 工具与技术
- **专家判断**
- **数据分析**（现金流分析、挣值分析等）
- **会议**

### 输出
- **风险管理计划**（核心文件）

| 内容 | 说明 |
|------|------|
| 风险管理策略 | 管理本项目风险的一般方法 |
| 方法论 | 具体工具及数据来源 |
| 角色与职责 | 领导者、支持者、团队成员 |
| 资金 | 应急储备和管理储备使用方案 |
| 时间安排 | 实施频率，纳入项目进度计划 |
| **风险类别（RBS）** | 风险分解结构，潜在风险来源的层级展现 |
| 干系人风险偏好 | 可测量的风险临界值 |
| **概率和影响矩阵** | 优先级排序规则，P×I评分 |

**RBS（风险分解结构）示例：**
```
0. 项目风险（所有来源）
├── 1. 技术风险（需求定义、估算、制约因素、技术过程...）
├── 2. 管理风险（项目管理、项目集/组合、运营、组织...）
├── 3. 商业风险（合同条款、内部采购、供应商、客户稳定性...）
└── 4. 外部风险（法律、汇率、地点/设施、环境/天气、竞争...）
```

## 15.4 识别风险

**作用：** 记录已识别风险和整体项目风险来源

### 输入
- 项目管理计划（风险管理计划、成本管理计划、进度管理计划、质量管理计划、范围基准...)
- 项目文件（假设日志、成本估算、持续时间估算、干系人登记册...）
- 采购文档
- 协议
- 事业环境因素
- 组织过程资产

### 工具与技术
- **专家判断**
- **数据收集**（头脑风暴、核查单、访谈、根本原因分析）
- **数据分析**（假设条件和制约因素分析、SWOT分析、文件分析）
- **人际关系与团队技能**（引导技术）
- **提示清单**（RBS底层风险类别清单）
- **会议**（风险研讨会）

### 输出
- **风险登记册**
  - 已识别风险清单（唯一标识号+描述）
  - 潜在风险责任人
  - 潜在风险应对措施
  - 风险触发条件
  - 受影响WBS组件
- **风险报告**（整体项目风险来源+已识别风险概述）
- **项目文件（更新）**

## 15.5 实施定性风险分析

**作用：** 对风险进行优先级排序，为后续分析（定性/定量）提供基础

### 输入
- 项目管理计划（风险管理计划）
- 项目文件（风险登记册、假设日志、干系人登记册）
- 事业环境因素
- 组织过程资产

### 工具与技术
- **专家判断**
- **数据收集**（访谈）
- **数据分析**（风险数据质量评估、风险概率和影响评估）
- **人际关系与团队技能**（引导技术）
- **风险分类**（按来源/受影响领域/共同根本原因）
- **数据表现**（概率和影响矩阵、层级图/气泡图）
- **会议**

### 输出
- **项目文件（更新）**（风险登记册更新：风险概率和影响评级、紧迫性/邻近性等参数、风险责任人、风险分类）
- **风险报告**（整体项目风险的当前等级、风险分析最重要假设条件、威胁和机会的优先级）

## 15.6 实施定量风险分析

**适用场景：** 大型/复杂项目、战略重要性高、合同要求、定量分析可行

### 输入
- 项目管理计划（风险管理计划、进度管理计划、成本管理计划）
- 项目文件（风险登记册、假设日志、里程碑清单、项目进度计划、项目预算估算）
- 事业环境因素
- 组织过程资产

### 工具与技术
- **专家判断**
- **数据收集**（访谈、德尔菲法、标杆对照）
- **人际关系与团队技能**（引导技术）
- **不确定性表现方式**（敏感性分析、期望货币价值EMV、决策树分析）
- **数据分析**（蒙特卡洛模拟、建模仿真）

### 输出
- **项目文件（更新）**（风险登记册更新：概率分布和量化风险排名、整体项目风险进度/成本预测）
- **风险报告**（定量分析结果：EMV、关键性分析、关键风险排名）

### 核心工具详解：

| 工具 | 说明 |
|------|------|
| **蒙特卡洛模拟** | 多次模拟计算概率分布，输出S曲线和直方图 |
| **敏感性分析** | 确定哪些风险影响最大，输出龙卷风图 |
| **期望货币价值（EMV）** | Σ(路径概率 × 路径净值) |
| **决策树** | 决策节点（□）vs 机会节点（○） |
| **关键性分析** | 活动在关键路径上出现的频率百分比 |

## 15.7 规划风险应对

**作用：** 制定应对方案、选择策略、商定应对行动

### 输入
- 项目管理计划（风险管理计划、成本管理计划、进度管理计划）
- 项目文件（风险登记册、风险报告、假设日志、经验教训登记册）
- 事业环境因素
- 组织过程资产

### 工具与技术
- **专家判断**
- **数据收集**（访谈、标杆对照）
- **人际关系与团队技能**（引导技术）
- **威胁应对策略**（上报、规避、转移、减轻、接受）
- **机会应对策略**（上报、开拓、分享、提高、接受）
- **应急应对策略**（弹回计划、挽回了计划）
- **整体项目风险应对策略**（规避、开拓、转移或分享、减轻或提高、接受）
- **数据分析**（备选方案分析、成本收益分析）
- **决策**

### 输出
- **变更请求**
- **项目管理计划（更新）**
- **项目文件（更新）**

### 策略对比：

| 策略类型 | 威胁策略 | 机会策略 |
|---------|---------|---------|
| 上报 | 上报项目集/组合/组织 | 上报项目集/组合/组织 |
| 主动型 | 规避、转移、减轻 | 开拓、分享、提高 |
| 被动型 | 接受 | 接受 |

## 15.9 监督风险

**作用：** 监督风险应对计划的实施、跟踪已识别风险、识别和分析新风险、评估有效性

### 输入
- 项目管理计划（项目管理计划组件、风险管理计划）
- 项目文件（问题日志、经验教训登记册、风险登记册、风险报告、项目进度计划、变更日志）
- 协议
- 事业环境因素
- 组织过程资产

### 工具与技术
- **数据分析**（储备分析、技术绩效分析）
- **风险审计**
- **会议**（风险审查会）

### 输出
- **项目文件（更新）**
- **变更请求**
- **工作绩效信息**
- **项目管理计划（更新）**

## 📝 常见考法提示

1. **风险策略区分**：考"某情景应采用哪种策略"——先判断是威胁还是机会，再选对应策略
2. **ITTO记忆**：每个过程都有输入/工具/输出，对照表15-1背诵
3. **概率和影响矩阵**：规划风险管理时作为**输出**（风险管理计划的内容）；定性风险分析时作为**工具**（给风险打分的依据）
4. **EMV计算**：决策树末端的概率×数值求和
5. **蒙特卡洛模拟**：定量风险分析的核心工具，输出S曲线
6. **龙卷风图**：敏感性分析工具，用于找最大影响因素
7. **会议分布**：规划风险管理、识别风险、定性分析、监督风险都有会议；定量分析**没有**会议
8. **输出差异**：规划风险应对输出**变更请求**；实施风险应对和监督风险输出**项目文件更新**；监督风险还额外输出**变更请求**和**工作绩效信息**
