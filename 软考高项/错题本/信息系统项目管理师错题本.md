## 🔴 **易错知识点记录**

### **1. 项目组合、项目集、项目的关系**
**错误题目：** 第 4 题  
**错误答案：** 项目集包含项目组合，项目组合包含项目  
**正确答案：** 项目组合包含项目集，项目集包含项目

**知识点：**
- **项目组合（Portfolio）**：最高战略层级，包含多个项目集和项目
- **项目集（Program）**：中间收益层级，包含多个相互关联的项目
- **项目（Project）**：基础交付层级，有明确目标和范围

**记忆口诀：** "组合管战略，项目集管收益，项目管交付"

**易错原因：** 容易混淆层级关系，误以为项目集最大

### **2. 项目管理办公室（PMO）的主要职能**
**错误题目：** 第 7 题  
**错误答案：** ACDE  
**正确答案：** ABDE

**选项解析：**
- A. 制定项目管理标准 ✓（PMO 的核心职能）
- B. 提供项目管理培训 ✓（支持项目团队）
- C. 管理具体项目 ✗（PMO 通常不直接管理具体项目，那是项目经理的职责）
- D. 分配项目资源 ✓（资源协调和分配）
- E. 监控项目绩效 ✓（跟踪和报告项目状态）

**关键区分：** PMO 是支持性、监督性机构，不是执行性机构。

### **3. 项目干系人范围**
**错误题目：** 第 8 题  
**错误答案：** 只选了 ABC（发起人、团队成员、客户）  
**正确答案：** ABCDE（发起人、团队成员、客户、供应商、政府监管部门）

**知识点：**
- **干系人定义：** 任何可能影响项目或被项目影响的个人、群体或组织
- **常见干系人：**
  - 内部：发起人、项目经理、团队成员、职能部门经理
  - 外部：客户、供应商、分包商、政府机构、社区、媒体、竞争对手
  - 间接：家庭成员、行业协会、公众

**记忆技巧：** "干系人 = 有关系的人"，范围要广

**易错原因：** 只想到直接参与项目的人，忽略了间接影响者

### **4. 项目组合管理 vs 项目集管理**
**错误题目：** 第 11 题  
**错误答案：** B) 主要管理相互关联的项目群  
**正确答案：** C) 与组织战略目标对齐，优化资源分配

**知识点：**
- **项目组合管理（Portfolio Management）**：
  - 战略层面：确保项目组合与组织战略一致
  - 关注：投资回报、资源优化、战略对齐
  - 特点：包含多个项目集和项目，不一定相互关联

- **项目集管理（Program Management）**：
  - 收益层面：协调相关项目以实现共同收益
  - 关注：项目间的依赖关系、协同效应
  - 特点：包含多个相互关联的项目

**对比记忆：**
| 维度 | 项目组合管理 | 项目集管理 | 项目管理 |
|------|--------------|------------|----------|
| 层级 | 战略层 | 收益层 | 交付层 |
| 关注点 | 战略对齐、投资优化 | 协同收益、依赖管理 | 项目交付、目标达成 |
| 包含关系 | 包含项目集和项目 | 包含相互关联的项目 | 单个项目 |
| 时间跨度 | 长期 | 中长期 | 短期 |

**易错原因：** 混淆了"战略对齐"和"收益协同"的概念层次

### **5. 项目 vs 运营的区分**
**错误题目：** 第 3 题（项目判断）  
**错误答案：** A,B,D,E  
**正确答案：** A,C,E

**选项解析：**
- A) 设计一款新产品的外观 ✓（有明确目标、临时性、独特性）
- B) 维护公司日常办公网络 ✗（这是运营工作，不是项目）
- C) 举办一场产品发布会 ✓（有明确目标、临时性、独特性）
- D) 工厂的日常生产流水线 ✗（这是运营工作，重复性）
- E) 开发一个微信小程序 ✓（有明确目标、临时性、独特性）

**关键区分：项目 vs 运营**

| 特征 | 项目 | 运营 |
|------|------|------|
| 性质 | 临时性 | 持续性 |
| 特点 | 独特性 | 重复性 |
| 时间 | 有明确的开始和结束 | 持续进行，无明确结束 |
| 目标 | 创造独特的产品、服务或成果 | 维持日常业务运行 |
| 导向 | 目标导向 | 效率导向 |

**记忆技巧：**
- **问自己：** "这是做新的事情，还是重复的事情？"
- **新的事情** → 项目
- **重复的事情** → 运营

**易错原因：** 将日常维护工作误认为是项目

### **6. IT 治理的主体**
**错误题目：** 第 9 题  
**题目**：IT 治理的主体是（ ）

**选项：**
- A. 信息技术部门
- B. 董事会和管理层
- C. 项目经理
- D. 外部审计机构

**错误答案：** A  
**正确答案：** B

**知识点解析：**
- IT 治理是**公司治理**的一部分
- 主体是**董事会和管理层**，不是 IT 部门
- IT 部门是执行者，不是决策者
- **记忆要点**：治理 = 决策层，管理 = 执行层

**易错原因：**
- 混淆了 IT 治理和 IT 管理的概念
- 误以为 IT 治理是 IT 部门的事

**对比记忆：**

| 维度 | IT 治理 | IT 管理 |
|------|--------|--------|
| **主体** | 董事会和管理层 | IT 部门 |
| **层次** | 决策层 | 执行层 |
| **目标** | 确保 IT 支持业务目标 | 高效运营 IT 系统 |
| **内容** | 决策权、责任、流程 | 计划、组织、控制 |
| **关系** | 治理是管理的前提 | 管理在治理框架下执行 |

**记忆口诀：**
> **治理是决策，管理是执行**  
> **董事会管治理，部门管管理**

**核心要点：**
```
IT 治理 → 提供制度、流程、决策机制
    ↓
信息化 → 在治理框架下推进
```

**记忆口诀：**
> **治理先行的，信息化后行**

### **8. 项目成本预算的组成结构**
**错误题目：** 成本预算单选题
**你的答案：** A
**正确答案：** B

**题目回顾：**
> 项目组正在对一个全新领域的项目进行成本预算，前期通过类比得出了项目的总体估算，以下做法**不正确的是**（ ）
> - A. 自顶向下，根据占用资源数量的多少将总成本加权分配给各工作包
> - B. 结合成本估算为各个工作包计算相应的应急储备和管理储备，汇总得到项目预算
> - C. 根据资源投入的时间段确定各项成本的预算支出时间计划，并形成项目成本预算计划
> - D. 邀请相关领域技术专家和项目客户，参与成本预算的讨论

**错选分析：**
- 你选了 A，但正确答案是 B
- A 选项的"加权分配"在全新领域项目中确实不够精确，但 B 选项的**概念错误更严重**

**核心知识点：项目预算的组成结构**

```
项目预算 = 成本基准 + 管理储备
                ↑
        成本基准 = 各控制账户汇总
                ↑
        控制账户 = 工作包成本估算 + 应急储备（控制账户层级）
                ↑
        工作包成本估算 = 活动成本估算 + 活动应急储备
```

**关键区分：应急储备 vs 管理储备**

| 维度 | 应急储备 | 管理储备 |
|------|----------|----------|
| **用途** | 应对已知风险（已识别） | 应对未知风险（不可预见） |
| **归属** | 包含在成本基准中 | 不包含在成本基准中 |
| **计算方式** | 由活动/工作包逐级汇总 | 针对整个项目设置，不分摊 |
| **动用权限** | 项目经理自行决定 | 需要额外审批 |

**为什么 B 是错的：**
- 管理储备是**不为各个工作包逐个计算**的
- 管理储备是针对**整个项目**设置的，直接加在成本基准之上
- B 选项说"为各个工作包计算相应的...管理储备，汇总得到..."，这是概念错误

**记忆口诀：**
> **应急储备分摊，管理储备不分**  
> **成本基准加管理储备，等于项目总预算**

**易错原因：** 混淆了应急储备（分摊）和管理储备（不分摊）的计算方式

### **9. 控制成本的数据分析技术 - EVM 术语**
**错误题目：** 控制成本数据分析技术单选题
**你的答案：** B
**正确答案：** A

**题目回顾：**
> 下列关于控制成本使用到的数据分析技术，描述不正确的是（ ）
> - A. "BAC为将要执行的工作所建立的全部预算总和，包含应急储备和管理储备"
> - B. "EAC完成所有工作所需的预期总成本，包括实际已支出的成本和要完成项目剩余工作所需的预期成本"
> - C. "ETC完成所有剩余项目工作的预计成本。不含前期已支出的成本"
> - D. "TCPI完成剩余工作所需的成本与剩余预算之比"

**错选分析：**
- 你选了 B，但正确答案是 A
- B 的描述是正确的（EAC = AC + ETC）
- A 的错误在于：**BAC 不包含管理储备**，只包含应急储备

**核心知识点：EVM 四大术语**

| 术语 | 全称 | 含义 | 公式 |
|------|------|------|------|
| **BAC** | 完工预算 | 全部工作的预算总和（含应急储备，不含管理储备） | - |
| **EAC** | 完工估算 | 实际成本 + 剩余工作估算 | EAC = AC + ETC |
| **ETC** | 完工尚需估算 | 剩余工作的预计成本（不含已支出） | - |
| **TCPI** | 完工尚需绩效指数 | 剩余工作的成本绩效要求 | (BAC - EV) / (BAC - AC) |

**关键结论：**
- **BAC = 成本基准**（包含应急储备，不包含管理储备）
- **项目总预算 = BAC + 管理储备**

**记忆口诀：**
> **BAC 不含管理储备**  
> **应急储备在基准内，管理储备在基准外**

**易错原因：** 对 BAC 的定义记忆不准确，误以为 BAC 包含管理储备

### **10. 项目成本管理的基本概念**
**错误题目：** 成本管理描述单选题
**你的答案：** C
**正确答案：** D

**题目回顾：**
> 下面有关成本管理的描述，不正确的是（ ）
> - A. 项目成本管理就是要确保在批准的预算内完成项目
> - B. 项目成本管理应当考虑项目干系人的需要
> - C. 成本估算和成本预算可由一个人在较短时间内完成
> - D. 项目成本管理重点关注应急储备和管理储备

**错选分析：**
- 你选了 C，但正确答案是 D
- C 的描述是正确的（小型项目可以由一人短时间完成）
- D 的错误在于：成本管理的**重点**是完成活动所需的**资源成本**，不是储备金

**核心知识点：**

| 成本管理原则 | 说明 |
|--------------|------|
| 确保在批准预算内完成 | 核心目标 |
| 考虑干系人需要 | 投资方看回报，用户看运营成本 |
| 生命周期成本 | 开发成本 + 运营成本 + 维护成本 |
| 结合价值工程 | 降低成本、缩短时间、提高质量 |

**四大约束关系：**
```
范围 ←→ 时间
  ↓       ↓
成本 ←→ 质量
```

**应急储备 vs 管理储备（再次强调）：**
- 这两个只是预算的**组成部分**
- 不是成本管理的**重点**
- 重点是**活动所需资源的成本**

**记忆口诀：**
> **成本管理重点是资源成本，不是储备金**

**易错原因：** 混淆了成本管理的组成要素和重点

### **12. TCPI（完工尚需绩效指数）计算**
**错题来源：** 图1-10:36
**你的答案：** （需确认）
**正确答案：** B（0.75）

**题目回顾：**
> 活动A预算1000元，总工期10天。第8天晚上检查，完成70%，实际成本600元。为按时完工且不超原预算，TCPI为多少？

**计算过程：**
- BAC = 1000元
- EV = 1000 × 70% = 700元
- AC = 600元
- TCPI = (BAC - EV) / (BAC - AC) = (1000 - 700) / (1000 - 600) = 300 / 400 = **0.75**

**选项分析：**
- A. 1.5 ❌（错误，可能混淆了公式）
- B. 0.75 ✅（正确）
- C. 1.17 ❌（这是当前 CPI = EV/AC = 700/600 ≈ 1.17）
- D. 0.8 ❌（这是 PV/BAC = 800/1000 = 0.8 或 SPI）

**易错点：**
- TCPI = 剩余工作 / 剩余资金，别记反了
- 1.17 是当前 CPI，不是 TCPI

### **13. 成本估算的描述（估算成本过程）**
**错题来源：** 图7-14:26
**你的答案：** B
**正确答案：** D

**题目回顾：**
> 关于成本估算的描述，正确的是（ ）
> - A. 只能用货币单位进行成本估算
> - B. 成本估算应排除通货膨胀、融资成本、应急成本
> - C. 主要在项目启动阶段进行
> - D. 应充分比较自制与外购、购买与租赁等多种方案

### **21. 典型vs非典型判断（关键！）**
**错题来源：** 15:47:21
**你的答案：** （需确认）
**正确答案：** C（150万）

**题目回顾：**
> BAC=100万，第3月底PV=50万，AC=60万，完成40%。
> "根据**当前项目成本绩效水平**预测"，EAC=？

**计算过程：**
- EV = 100万 × 40% = 40万
- CPI = EV / AC = 40 / 60 = **0.67**
- 典型 EAC = BAC / CPI = 100 / 0.67 ≈ **150万**

**为什么用典型？**

| 关键词 | 意味着 | 公式 |
|--------|--------|------|
| "按当前绩效水平预测" | 当前CPI会持续 | **典型：除法** |
| "偏差是偶然的" | 未来按原计划 | 非典型：加法 |

**判断口诀：**
> 听到"按当前绩效"、"CPI将持续" → **典型（除法）**
> 听到"偶然偏差"、"未来按计划" → **非典型（加法）**

**易错点：**
- 本题关键词"**根据当前项目成本绩效水平**"直接暗示用典型
- 典型 = 认为当前低效率会延续 = BAC/CPI
- 非典型 = 认为问题已解决，剩余按原计划 = AC+(BAC-EV)

```
                    ┌─────────────────────────────┐
                    │      项目总预算/项目预算       │
                    │    （总授权资金，包含管理储备）  │
                    └──────────────┬──────────────┘
                                   │
                    ┌──────────────┴──────────────┐
                    │                             │
                    ▼                             ▼
         ┌─────────────────────┐       ┌─────────────────┐
         │      成本基准        │       │   管理储备       │
         │  （绩效测量基准）     │       │ （不含在基准内）   │
         └──────────┬──────────┘       └─────────────────┘
                    │
         ┌──────────┴──────────┐
         │                     │
         ▼                     ▼
  ┌─────────────┐     ┌─────────────┐
  │ 估算成本汇总  │  +  │  应急储备    │
  │（工作包成本） │     │（已知-未知） │
  └─────────────┘     └─────────────┘
```

**关键公式：**

| 概念 | 包含管理储备？ | 包含应急储备？ | 用于绩效测量？ |

| 成本基准 | ❌ | ✅ | ✅ |
| 项目总预算 | ✅ | ✅ | ❌ |

**记忆口诀：**
> "项目总"管全，基准只是参
> "管理储备"在"项目总"里，不在"基准"里

**易错点：**

想象自己管一个跨国家团队（北/上/印/日），裁剪沟通过程时要考虑：
- 物理上怎么分布 → 物理地点
- 用什么技术开会 → 沟通技术
- 开会写文档用什么话 → 语言
- 这些人是谁，关心什么 → 干系人
- 经验怎么留下来 → 知识管理

**本题教训：**  
题目问"包括"时，常见陷阱是只记①②③漏④⑤。背书时要完整记忆五个因素，不要中途停下。

**知识点关联：**  
- 规划沟通管理（规划过程组）→ 制定沟通策略
- 沟通技术、沟通方法、沟通模型的区别也是高频考点
