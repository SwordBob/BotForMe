# A股量化交易系统

## 环境依赖

```bash
pip3 install baostock pandas numpy backtrader akshare
```

## 核心脚本

### 1. 选股系统（推荐优先运行）
```bash
python3 ~/.openclaw/workspace/skills/a-stock-quant/scripts/选股系统.py
```
- 均线多头排列筛选：MA5 > MA20 > MA60
- ADX 趋势强度确认（默认 >25，符合则说明趋势明确）
- 先用 `ADX>30` 扫描，再用 `ADX>25` 降阈值扫描
- 如需更低阈值，直接在脚本中改 `adx > thresh` 的 thresh 值

**选股逻辑**：
- ADX > 30 = 强趋势（趋势跟随策略最佳时机）
- ADX < 20 = 震荡市（适合网格交易，趋势策略回避）
- ADX 20-30 = 中性市（谨慎操作）

### 2. 趋势跟随回测（双均线策略）
```bash
python3 ~/.openclaw/workspace/skills/a-stock-quant/scripts/双均线策略.py
```
- 买入信号：MA5 上穿 MA20（金叉）
- 卖出信号：MA5 下穿 MA20（死叉）
- 对比基准：买入持有

### 3. 网格交易策略（猴市克星）
```bash
python3 ~/.openclaw/workspace/skills/a-stock-quant/scripts/A股网格策略.py
```
- 每跌 2% 买，每涨 2% 卖
- 适合震荡无趋势的猴市（A股 2023-2025 典型特征）
- 平均超额收益 +2.38%（7/9 只跑赢买入持有）

## 策略决策树

```
市场当前状态？
│
├─ 有明确趋势（ADX > 30，MA多头排列）？
│   └─ YES → 趋势跟随策略（双均线/MA+MACD）
│
├─ 震荡无方向（ADX < 20）？
│   └─ YES → 网格交易策略
│
└─ 中性（ADX 20-30）？
    └─ 观望，等待信号
```

## A股数据格式

- 上海：`sh.600519`（贵州茅台）
- 深圳主板：`sz.000001`（平安银行）
- 创业板：`sz.300750`（宁德时代）
- 科创板：`sh.688981`（中芯国际）

## 重要结论（实测结果）

| 策略 | A股2023-2025表现 | 适合场景 |
|------|-----------------|---------|
| 网格交易 | 平均超额 +2.38%（7/9跑赢） | 猴市/震荡 |
| 纯双均线 | 个股分化严重（五粮液+48% / 茅台-29%） | 有趋势的个股 |
| MA+MACD | ADX阈值在A股偏严，容易空仓错过机会 | 需调低ADX阈值 |
| 买入持有 | 大盘ETF（如沪深300）+0.74% | 懒人基准 |

## 注意事项

- baostock 单次查询有时会连接重置（Errno 54），加 `time.sleep(0.1)` 处理
- 手续费默认 0.1%（万1 + 过户费）
- 网格策略回撤计算有简化 bug（显示0%），实际回撤需手动核实
- 趋势策略在A股2023-2025表现差，根本原因是**猴市无趋势**
