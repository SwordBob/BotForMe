## 16.1 管理基础

### 16.1.1 协议／采购合同

**核心定义**：
- 项目采购管理 = 从项目团队外部采购或获取所需产品、服务或成果
- 采购合同是受法律约束的协议，可以是合同、SLA、MOA、协议备忘录或订购单

**合同特点**：
- 合同未规定的事项不具法律强制力
- 合同需要经过更多审批程序（通常涉及法务部）
- 在世界各地，用不同名称称呼采购部门（购买部、合同部、采购部、收购部）

**重要原则**：
- 文化和当地法律对合同及其可执行性均有影响
- 合同应明确说明预期可交付成果和结果，包括知识转移

### 16.1.2 管理新实践

| 新实践 | 说明 |
|--------|------|
| **工具的改进** | BIM软件应用日益广泛，在线工具发布采购广告 |
| **更先进的风险管理** | 在合同中准确将风险分配给最有能力管理的一方 |
| **变化中的合同签署实践** | 超大型项目增多，国际合同标准日益普遍 |
| **物流和供应链管理** | 采购周期长的产品需提前订购，明确主要和备选渠道 |
| **技术和干系人关系** | 网络摄像机记录施工现场情况，减少争议 |
| **试用采购** | 决定大批量采购前，先试用多个候选卖方 |

## 16.2 项目采购管理过程概览

### 三个核心过程

| 过程 | 作用 |
|------|------|
| **规划采购管理** | 记录采购决策、明确采购方法、识别潜在卖方 |
| **实施采购** | 获取卖方应答、选择卖方并授予合同 |
| **控制采购** | 管理采购关系、监督合同绩效、实施必要变更和纠偏、关闭合同 |

### 采购过程总表（ITTO）

#### 规划采购管理
| 类别 | 内容 |
|------|------|
| **输入** | 采购管理计划、采购策略、立项管理文件、项目章程、项目管理计划、项目文件、事业环境因素、组织过程资产|
| **工具与技术** | 专家判断、数据收集（市场调研）、数据分析（自制或外购分析）、供方选择分析、会议 |
| **输出** | 采购工作说明书、招标文件、自制或外购决策、独立成本估算、供方选择标准、变更请求、项目文件更新、组织过程资产更新 |

#### 实施采购
| 类别 | 内容 |
|------|------|
| **输入** | 项目管理计划、项目文件、采购文档、卖方建议书、事业环境因素、组织过程资产 |
| **工具与技术** | 专家判断、广告、投标人会议、数据分析（建议书评估）、谈判 |
| **输出** | 选定的卖方、协议、变更请求、项目管理计划更新、项目文件更新、组织过程资产更新 |

#### 控制采购
| 类别 | 内容 |
|------|------|
| **输入** | 项目管理计划、项目文件、采购文档、协议、工作绩效数据、批准的变更请求、事业环境因素、组织过程资产 |
| **工具与技术** | 专家判断、**索赔管理**、数据分析（绩效审查、挣值分析、趋势分析）、检查、审计 |
| **输出** | 采购关闭、采购文档更新、工作绩效信息、变更请求、项目管理计划更新、项目文件更新、组织过程资产更新 |

### 16.2.2 裁剪考虑因素

| 因素 | 考虑点 |
|------|--------|
| 采购复杂性 | 一次主要采购 vs 多次采购 |
| 物理地点 | 同一/邻近 vs 不同时区/国家 |
| 法规环境 | 组织政策 vs 当地法律法规 |
| 承包商可用性 | 是否有合格承包商可供选择 |

### 16.2.3 敏捷与适应方法

- 与特定卖方协作，风险共担式采购模型
- 大型项目可采用主体协议（MSA）+ 敏捷附录的方式
- 变更只针对敏捷工作，不影响主体协议

## 16.3 规划采购管理

**主要作用**：确定是否从外部获取货物和服务，如果是，则确定在什么时间、以什么方式获取

### 16.3.1 输入

1. **立项管理文件**：商业需求和成本效益分析
2. **项目章程**：目标、总体里程碑、预先批准的财务资源
3. **项目管理计划**：
   - 范围管理计划、质量管理计划、资源管理计划、范围基准
4. **项目文件**：
   - 风险登记册、干系人登记册、需求文件、需求跟踪矩阵、里程碑清单、资源需求、项目团队派工单
5. **事业环境因素**：市场条件、可获得的产品/服务/成果、卖方情况、典型条款和条件
6. **组织过程资产**：预审合格卖方清单、正式采购政策/程序/指南、**合同类型**

### 16.3.2 工具与技术

| 工具 | 说明 |
|------|------|
| **专家判断** | 采购与购买、合同类型和合同文件、法规及合规性 |
| **数据收集（市场调研）** | 考察行业情况和具体卖方能力 |
| **数据分析（自制或外购分析）** | 确定自制还是外购；考虑资源配置、专业技术、风险等；可用NPV/IRR/ROI等财务指标辅助决策 |
| **供方选择分析** | 最低成本、仅凭资质、基于质量/技术方案、基于质量和成本、唯一来源、固定预算 |
| **会议** | 确定管理和监督采购的策略 |

#### 供方选择分析方法对比

| 方法 | 适用场景 |
|------|---------|
| **最低成本** | 标准化常规采购，有成熟标准 |
| **仅凭资质** | 采购价值小，不值得完整评选 |
| **基于质量和成本** | 成本+质量都要考虑，风险高时质量优先 |
| **基于技术方案** | 技术能力至关重要，先评技术再谈价 |
| **唯一来源** | 有充分理由的特殊情况 |
| **固定预算** | SOW精确、预算固定不超 |

### 16.3.3 输出

1. **采购管理计划**：采购活动、里程碑、指标、角色职责、风险事项、预审合格卖方
2. **采购策略**：
   - **交付方法**：专业服务（不分包/可分包/合资/仅代表）、工业施工（交钥匙/DB/DBB/DBO/BOOT）
   - **合同支付类型**：总价、成本补偿、工料
   - **采购阶段**：顺序安排、绩效指标、里程碑、阶段过渡标准
3. **采购工作说明书 (SOW)**：规格、数量、质量水平、绩效数据、履约期间、工作地点
4. **招标文件**：
   - **RFI**（Request for Information，信息邀请书）：早期了解市场，"你们能做什么？"——我还不确定买什么，先探路
   - **RFQ**（Request for Quotation，报价邀请书）：需求明确后询价，"多少钱？"——我知道要什么，问你价格
   - **RFP**（Request for Proposal，建议邀请书）：需求不明确，需要方案，"怎么解决？"——最正式，需严格遵守规则
5. **自制或外购决策**
6. **独立成本估算**：作为评价卖方报价的对照基准
7. **供方选择标准**：能力、成本、交付日期、技术专长、经验、关键员工、财务稳定性等

## 16.4 实施采购

**主要作用**：选定合格卖方并签署法律协议（合同）

### 16.4.1 输入

- 项目管理计划（范围/需求/沟通/风险/采购/配置管理计划，成本基准）
- 项目文件（需求文件、项目进度计划、风险登记册、干系人登记册、经验教训登记册）
- **采购文档**：招标文件、采购工作说明书、独立成本估算、供方选择标准
- **卖方建议书**
- 事业环境因素
- 组织过程资产

### 16.4.2 工具与技术

| 工具 | 说明 |
|------|------|
| **专家判断** | 建议书评估、技术/职能领域、法律法规、谈判 |
| **广告** | 大众/行业出版物刊登广告，扩充潜在卖方名单 |
| **投标人会议** | 确保所有潜在投标人有清楚且一致的理解，无特别优待 |
| **数据分析（建议书评估）** | 评估建议书是否对招标文件包做出完整充分响应 |
| **人际关系与团队技能（谈判）** | 为达成协议而进行的讨论，签署前对合同结构、权利义务等澄清 |

### 16.4.3 输出

- **选定的卖方**
- **协议（合同）**：工作说明书/可交付成果、进度计划、绩效报告、定价和支付、验收标准、激励惩罚、担保、变更处理、终止条款等
- 变更请求
- 项目管理计划更新
- 项目文件更新
- 组织过程资产更新

#### 实施采购的"项目文件"输入（★★★ 常考辨析）

> ⚠️ **易混淆点**：实施采购的"项目文件"不包括招标文件！

| 属于"项目文件" | 不属于"项目文件"（属于"采购文档"）|
|---------------|--------------------------------|
| 需求文件 | 招标文件 |
| 项目进度计划 | 采购工作说明书 |
| 风险登记册 | 独立成本估算 |
| 干系人登记册 | — |
| 经验教训登记册 | — |

> **记忆口诀**：需进风干经（需求/进度/风险/干系人/经验）

## 16.5 控制采购

**主要作用**：确保买卖双方履行法律协议，满足项目需求

### 16.5.1 输入

- 项目管理计划（需求/风险/采购/变更管理计划，进度基准）
- 项目文件（假设日志、需求文件、需求跟踪矩阵、里程碑清单、风险登记册、干系人登记册、质量报告、经验教训登记册）
- **采购文档**：工作说明书、支付信息、工作绩效信息、计划、图纸、往来函件
- **协议**
- **工作绩效数据**：技术绩效、已启动/进行中/已结束活动、已产生/投入成本、已付款情况
- 批准的变更请求
- 事业环境因素
- 组织过程资产

### 16.5.2 工具与技术

| 工具 | 说明 |
|------|------|
| **专家判断** | 职能领域（财务/工程/设计/供应链）、法律法规、索赔管理 |
| **索赔管理** | 有争议的变更→索赔→谈判→ADR→仲裁/诉讼 |
| **数据分析**：绩效审查、挣值分析(EVA)、趋势分析 | 对照协议审查质量/资源/进度/成本绩效 |
| **检查** | 对承包商工作进行结构化审查，包括现场联合巡检 |
| **审计** | 对采购过程的结构化审查 |

#### 控制采购工具区分（★★★ 常考）

| 工具 | 用途 | 常见混淆点 |
|------|------|----------|
| **绩效审查** | 审查卖方工作是否符合合同（质量/范围/进度） | ❌ 不能用来算EAC |
| **趋势分析** | 计算EAC、分析成本/进度绩效趋势（改善还是恶化） | ✅ 这是算完工估算的工具 |
| **挣值分析(EVA)** | 综合分析进度和成本绩效（PV/EV/AC/SV/CV） | — |

> ⚠️ **易错点**：绩效审查 ≠ 趋势分析。前者审合同合规性，后者算完工估算。

### 16.5.3 输出

- **采购关闭**：正式书面通知合同完成（按时按质按技术要求交付、无未决索赔/发票、最终款项付清）
- **采购文档更新**：支持合同的全部进度计划、已提出/批准的变更、技术文件、工作绩效信息
- **工作绩效信息**
- **变更请求**
- 项目管理计划更新
- 项目文件更新（经验教训、风险登记册、干系人登记册等）
- 组织过程资产更新（支付计划、卖方绩效评估、预审合格清单更新、经验教训知识库、采购档案）

## 16.6 项目合同管理

### 合同类型（★★★ 超高频考点）

#### 总价合同（Fixed-Price）
| 类型 | 特点 | 适用场景 |
|------|------|---------|
| **固定总价 FPP** | 价格固定，不变 | 工作范围明确，变更少 |
| **总价加激励 FPIF** | 设价格上限，超支卖方承担 | 需激励卖方控制成本 |
| **总价加经济调整 FPEPA** | 根据通胀等条件调价 | 跨年度、多货币、长周期合同 |

#### 成本补偿合同（Cost-Reimbursable）
| 类型 | 特点 | 适用场景 |
|------|------|---------|
| **成本加固定费用 CPFF** | 实报实销+固定管理费 | 范围稳定，只需补偿合理成本 |
| **成本加激励 CPIF** | 实际vs目标成本按比例分担（如8:2） | 需激励卖方控成本 |
| **成本加奖励 CPAF** | 奖励由买方主观决定，不可申诉 | 信任卖方，关系导向 |

#### 工料合同 (T&M)
- **特点**：按工时材料和固定费率结算，兼具总价和成本补偿特点
- **适用**：工作范围无法准确定义，需灵活调整（常见于人员外包、专家咨询）

#### 合同类型选择
| 场景 | 推荐 |
|------|------|
| 范围明确、变更少 | 总价合同 |
| 范围不确定、风险高 | 成本补偿合同 |
| 无法编制准确SOW | 工料合同 |
| 预算固定 | 固定预算方法 |

#### 合同类型与风险分配的关系（★★★ 常考）

| 风险承担方式 | 对应合同类型 | 说明 |
|------------|------------|------|
| **双方分担风险** | **工料合同** | 工作量/成本不确定时，实报实销双方共担 |
| **买方承担成本风险** | **成本补偿合同** | 卖方实报实销，超支由买方承担（CPFF/CPIF/CPAF） |
| **卖方承担成本风险** | **总价合同** | 卖方按固定价执行，超支自行消化（FPP/FPIF/FPEPA） |

> **记忆口诀**：分（工料双方分担）→ 补（成本补偿买方担）→ 包（总价卖方包）

### 索赔管理（★★★ 高频考点）

#### 索赔流程

```
索赔事件发生
    ├─[28天内]→ 提出索赔意向通知
    │               │
    │               └─[再28天内]→ 报送索赔报告
    │                                    │
    │                         监理工程师答复(28天内)
    │                              ↓
    │                    逾期未答复 → 视为认可
    │                              ↓
    │                    持续索赔 → 28天内终了报告
    │                              ↓
    │                      仍不赔付 → 仲裁/诉讼
```

**时间累计：事件发生 → 索赔报告 = 最长56天（28+28）**

#### 索赔时效要点（全部28天，记忆口诀：想索赔？28天！）

| 时限 | 动作 |
|------|------|
| 事件发生后 **28天内** | 提出索赔意向通知 |
| 发出通知后 **28天内** | 报送索赔报告 |
| 收到报告后 **28天内** | 监理工程师答复 |
| 工程师 **逾期未答复** | 视为索赔已认可 |
| 索赔事件终了后 **28天内** | 提交持续索赔最终报告 |

#### 索赔原则

> **有理性、依据的有效性、计算的正确性**

#### 争议解决顺序（★★★ 常考）

```
谈判（首选） → ADR替代争议解决方法（调解/仲裁）→ 诉讼
```

> ⚠️ **易错点**：解决索赔和争议的**首选方法是谈判**，ADR只是备选方案

#### 索赔报告内容

1. 总论部分
2. 根据部分
3. 计算部分
4. 证据部分

---

### 合同解释的原则

| 原则 | 核心要点 |
|------|---------|
| **主导语言** | 两种语言文本，以主导语言为准 |
| **适用法律** | 按合同规定的适用法律解释 |
| **整体解释** | 特殊>一般；具体>笼统；手写>印刷；单价>总价；文字>数字；规范>图纸 |
| **公平诚信** | 含糊之处，按**不利于起草方**（通常为买方）的原则解释 |

## 📝 常见考法提示

1. **合同类型区分**：给出场景判断用哪种合同（范围明确→总价，范围不确定→成本补偿）
2. **合同与风险分配**：双方分担→工料；买方承担→成本补偿；卖方承担→总价
3. **ITTO记忆**：三个过程的输入/工具/输出对照表背诵
4. **索赔流程**：28天时效是高频考点
5. **索赔争议解决顺序**：谈判首选 → ADR备选 → 诉讼
6. **合同解释原则**：整体解释原则的具体优先级顺序
7. **供方选择方法**：区分6种方法的适用场景
8. **CPIF成本分担计算**：实际成本>目标成本时，买方和卖方按比例分担
9. **采购文档区分**：RFI/RFQ/RFP三种文件的适用场景
10. **项目文件 vs 采购文档**：实施采购的"项目文件"不包括招标文件
11. **绩效审查 vs 趋势分析**：EAC完工估算用趋势分析，不是绩效审查
